# Pegel 0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A KDE tray program that shows, on a click, the quota of all AI coding accounts from `quota-axi`.

**Architecture:** Built like Hafen: a static QML module `Pegel` contains the C++ types (`Quota`, `Tray`, `Launcher`) and the QML user interface. All computing and deciding lives in `src/model.mjs` and runs under Node and in Qt's JavaScript engine. C++ only starts processes, reads directories and draws the tray icon.

**Tech Stack:** C++20, Qt ≥ 6.5 (Core, Gui, Widgets, Qml, Quick, QuickControls2, QuickTest, LinguistTools), KF6 Kirigami, KF6 StatusNotifierItem, KF6 DBusAddons, CMake, CPack, Node for the model tests.

**Spec:** `docs/superpowers/specs/2026-11-24-pegel-design.md`

**Template:** Hafen in the sibling folder `../hafen`, branch `feature/ui-tests`. Where a task says "like Hafen", the named Hafen file is taken over and `hafen`/`Hafen`/`HAFEN` is replaced with `pegel`/`Pegel`/`PEGEL`. The SPDX header of every file reads `GPL-3.0-or-later`, copyright holder "Pegel contributors".

## Global Constraints

- Name "Pegel", program `pegel`, app ID `io.github.bdgraue.Pegel`, QML module `Pegel`, settings in `~/.config/pegel/pegel.conf`, version 0.1.0.
- All numbers come from `quota-axi --json --full`. Pegel calls no provider API and reads no credentials.
- `--allow-keychain-prompt` and `--allow-claude-inference` are never passed.
- A window without `percentUsed` shows "—" and never "0 %".
- `schemaVersion` must be 5 or 6, anything else is a read error.
- Public repository: test data, documents and commit messages mention only `example.com` and invented names, no path starts with a real home directory. The repository contains no provider logos.
- `src/model.mjs` uses neither object spread nor `Array.prototype.flatMap` nor destructured parameters in sort functions.
- The source texts of the user interface are English with `qsTr`. README, changelog and everything else in the repository are English.
- Third-party symbols (Qt, KF6, Kirigami) are looked up in the headers under `/usr/include` or in `../hafen` before use.
- Commits only when the user has approved them. Subject lines short, imperative and English.
- Levels: 0 below 60 %, 1 from 60 %, 2 from 80 %, 3 from 92 %.
- Times: read every 5 minutes (configurable from 1 to 60), on opening after 60 seconds, 30 seconds after a reset, timeout 60 seconds. A reading is old after two read intervals.

## Review Focus

1. The login shell writes its own text before or after the JSON. Expected: Pegel reads the JSON anyway. Test in Task 2 (`extractJson`).
2. The computer was suspended. Expected: after waking up, Pegel reads immediately instead of showing numbers up to 5 minutes old as fresh. Test in Task 5 (`readDue`) and 8.
3. `percentUsed` is above 100 or below 0. Expected: the text shows the reported value, the bar stays within its bounds. Test in Task 3.
4. A profile folder contains a colon, the separator of `QUOTA_AXI_CLAUDE_PROFILES`. Expected: Pegel rejects the folder with a reason instead of passing two wrong paths. Test in Task 6.
5. `pegel.conf` contains something unreadable in a JSON field. Expected: Pegel starts, names the field in the window and overwrites it only when the user changes the setting. Test in Task 6 (`parseSetting`) and 10.

## Shared Types

Timestamps are milliseconds since 1970, `null` means unknown. Texts are `""` when they are missing.

```
Report  { readAt, lanes: Lane[] }
Lane    { key, provider, label, plan, status, notSetUp, refreshedAt,
          error, reason, remedyCommand, retryAfter, profileDir,
          email, organization,
          credits: { remaining, unlimited, unit } | null,
          runway: { status, remaining, exhaustedAt, freeAt, confident } | null,
          windows: Window[] }
Window  { id, label, kind, percentUsed, resetsAt, startsAt, cycleSeconds,
          shareOf, untrusted, exhaustedAt,
          amount: { used, limit, unit } | null }
Options { hidden: string[], names: { [key]: string },
          kinds: { session, weekly, monthly, model, other },
          showNotSetUp, notify, threshold, refreshMs }
```

`kinds.other` covers the kinds `credits` and `unknown` and is on by default. The spec names four kinds; the fifth is needed because OpenCode Go reports its 5-hour window as `unknown`.

The model tests use `const NOW = Date.parse("2026-01-15T12:00:00Z")`. `tests/setup.mjs` sets `process.env.TZ = "UTC"`, `tests/ui/main.cpp` sets `TZ=UTC` via `qputenv` before creating the application.

### Task 2: Read the answer

**Files:**
- Modify: `src/model.mjs`
- Test: `tests/model.cases.mjs`

**Interfaces:**
- Produces: `SCHEMA_VERSIONS = [5, 6]`, `STATUSES = ["fresh", "stale", "unavailable", "auth_required", "rate_limited", "error"]`.
- Produces: `extractJson(stdout: string): string`, the text from the first `{` to the last `}`; throws without a pair of braces.
- Produces: `parseReport(stdout: string, readAt: number, disabledDirs: string[]): Report`.

Rules for `parseReport`:

- `key` is `provider + "/" + (accountKey ?? "default")`.
- `refreshedAt` is `state.refreshedAt`; if it is missing with status `fresh`, `readAt` applies.
- `profileDir` is `accountLocator.path`. Rows whose `profileDir` is in `disabledDirs` are dropped.
- `runway` comes from the scope `all_models` when its `status` is `known`: `remaining` is `effectivePercentRemaining`, `exhaustedAt` is `runway.projectedExhaustedAt`, `confident` is `projectionConfidence === "established"`, `freeAt` is the `resetsAt` of the window `runway.limitingWindowId`. Otherwise `null`.
- Windows: `cycleSeconds` is `windowSeconds`, otherwise `(resetsAt − startsAt) / 1000`, otherwise `null`. `untrusted` is true when the `id` is in `state.untrustedWindowIds`. `exhaustedAt` is `pace.projectedExhaustedAt`, but only with `projectionConfidence === "established"`. `amount` is `{ spentUsd, limitUsd, "$" }` or `{ usedCredits, limitCredits, creditUnit }` when both numbers are present.
- Errors as `Error` with these texts: "quota-axi printed no JSON.", "quota-axi reported schema version %1; Pegel knows 5 and 6.", "quota-axi reported the account %1 twice.", "quota-axi reported the unknown status %1.", "quota-axi reported no provider list."

### Task 3: Present a limit window

**Files:**
- Modify: `src/model.mjs`
- Test: `tests/model.cases.mjs`

**Interfaces:**
- Consumes: `Lane`, `Window`, `level`.
- Produces: `until(ms: number): string`, `ago(ms: number): string`, `clock(at: number, now: number): string`, `isOld(lane, now, refreshMs): boolean`, `windowView(lane, window, now, refreshMs): WindowView`.

```
WindowView { label, percentText, fill, level, elapsed, detail, dimmed, indent }
```

Rules:

- `until`: "18 min", "1 h 18 min", "2 d 5 h". `ago`: "just now" below one minute, "12 min ago", "3 h ago", "2 d ago".
- `clock`: on the same calendar day "22:37", on one of the next six days "Wed 22:37", after that "in 12 d". The weekday abbreviations go through `qsTr` one by one.
- `isOld`: status `stale`, or `refreshedAt` is `null`, or `now − refreshedAt > 2 × refreshMs`.
- `label`: "%1 hours" with `Math.round(cycleSeconds / 3600)` for `session` (5 without a cycle), "Week" for `weekly`, "Month" for `monthly`, otherwise `window.label`. If two windows of the entry have the same kind, `window.label` applies to both.
- `percentText`: `Math.round(percentUsed) + " %"`, without a value "—". `fill` is `percentUsed / 100`, clamped to 0 to 1, without a value `null`. `level` without a value `null`.
- The reset is known when `resetsAt` is not `null` and lies after `lane.refreshedAt`. It has passed when it is known and does not lie after `now`.
- `elapsed`: `1 − (resetsAt − now) / (cycleSeconds × 1000)`, clamped to 0 to 1; `null` without a cycle, without a known reset or after the reset.
- `detail`, parts joined with " · ", in this order of precedence:
  1. `untrusted`: only "not trusted by quota-axi".
  2. Reset passed: only "no new reading since the reset".
  3. Without `percentUsed`: the amount as "12.40 of 50.00 $", otherwise empty. The decimal separator goes through the translation as its own text `qsTr(".")`.
  4. Otherwise: "resets in %1" with a known reset; the pace note when `elapsed` is at least 0.03; for kind `model` "empty around %1" when `exhaustedAt` lies between `now` and `resetsAt`.
- Pace: `d = Math.round(percentUsed − elapsed × 100)`; with a distance below 5 points "on pace", otherwise "%1 % over pace" or "%1 % under pace".
- `dimmed`: `untrusted`, reset passed or `isOld(lane)`. `indent`: `shareOf` is set.

### Task 4: Entries

**Files:**
- Modify: `src/model.mjs`
- Test: `tests/model.cases.mjs`

**Interfaces:**
- Consumes: `Report`, `Lane`, `Options`, `clock`, `ago`, `isOld`.
- Produces: `laneNames(lanes, names): { [key]: string }`, `visibleLanes(report, options): Lane[]`, `notSetUpCount(report): number`, `laneSummary(lane, now): string`, `laneProblem(lane, now): { text, command } | null`, `laneAge(lane, now, refreshMs): string`, `creditsText(lane): string`, `planText(lane): string`.

Rules:

- `laneNames`: The name is `label`. If an entry has a custom name in `names`, or if several entries share the provider, it reads `label + " · " + suffix`. The suffix is the custom name, otherwise taken from `profileDir`: the folder name `.claude` becomes "Default", `.claude-<x>` becomes `<x>`, any other folder name stays. Without `profileDir` the suffix is the part of the key after the slash.
- `visibleLanes`: not in `options.hidden`, and `notSetUp` only with `options.showNotSetUp`. Order as delivered.
- `laneSummary` from `lane.runway`: `through_reset` becomes "%1 % left · lasts until the reset"; `projected_exhaustion` becomes "%1 % left · empty around %2", without `confident` only "%1 % left"; `exhausted_now` becomes "used up · free from %1", without `freeAt` "used up"; otherwise empty.
- `laneProblem`: `null` when the status is `fresh` or `stale` and there are windows. Otherwise by rank: `reason === "credentials_expired"` becomes "Session expired"; `auth_required` becomes "Sign-in required"; `rate_limited` becomes "Rate limit until %1" with `clock(retryAfter)`, without `retryAfter` "Rate limited"; otherwise "Not available: %1" with `error`, without `error` "Not available". `command` is `remedyCommand`.
- `laneAge`: empty when the entry is not old; otherwise "Reading from %1" with `ago`, without `refreshedAt` "Outdated reading".
- `creditsText`: "Credit: unlimited" with `unlimited`, "Credit: %1 %2" with `remaining > 0`, otherwise empty.
- `planText`: `plan` with a capital first letter.

Rules:

- A window counts when its entry is visible, set up and not old, it has a `percentUsed`, no `shareOf`, is not `untrusted`, its reset has not passed and its kind is checked in `options.kinds` (`credits` and `unknown` under `other`).
- `trayState`: `fill` and `level` from the highest counted value, both `null` without counted windows. `warning` is true with a `readError` or when a visible, set-up entry has a `laneProblem`. `tooltip`: with a `readError` its title as the first line, then per entry with counted windows "<name>: 82 %".
- `notifications`: `memory` is `{ primed, cycles: { "<key>|<id>": { resetsAt, warned, exhausted } } }`, initial value `{ primed: false, cycles: {} }`. The first call only remembers the state; `warned` and `exhausted` count as already reported there, as far as they are reached. After that, per counted window: if `resetsAt` has changed, a new cycle begins; if the old one was `exhausted` and the new value is below 100, "available again" is sent. If the value reaches 100 and `exhausted` was false, "used up" is sent; `warned` then counts as reported too. If it otherwise reaches `options.threshold` and `warned` was false, the warning is sent. With `options.notify === false`, `messages` stays empty and `memory` keeps running.
- Messages: the title is the name of the entry. Texts "%1 at %2 %" (icon `dialog-warning`), "%1 used up, free from %2" or without a reset "%1 used up" (icon `dialog-warning`), "%1 available again" (icon `io.github.bdgraue.Pegel`). `%1` is the `label` from `windowView`.
- `nextResetRead`: the earliest known, future `resetsAt` of a window that counts apart from the reset check and has reached `options.threshold`, plus `RESET_READ_DELAY_MS`.
- `readDue`: `now − lastAttemptAt >= refreshMs`. The read loop checks this every 30 seconds instead of running a timer over the whole interval. This way a read is due immediately after a suspend.
